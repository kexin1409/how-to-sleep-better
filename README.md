## 这是什么

一本按「性价比」排序的睡眠书。每条建议写清三件事：**花掉什么**（钱、时间、毅力）、**换回什么**（睡得着、睡得沉、白天不困、长期健康）、**证据多硬**（A/B/C 三级）。来源只引期刊论文、官方机构报告（AASM、NSF、WHO、CDC 等）和临床指南，不引二手转述。

它参考了 [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)（《高性价比人生指南》）与《高性价比饮食指南》的写法：同样是「成本 × 收益 × 证据等级」的条目制，同样是单文件、零依赖、手机可读的阅读页。饮食那本讲一日三餐，这本专讲每晚那 6–9 小时。

**本项目从未发行、也不会发行任何代币或数字资产。**

## 这本书想回答的问题

- 到底谁需要 8 小时？还是 7 小时就够？
- 最便宜的「安眠药」是什么？（固定起床时间）
- 晨光、黑暗、凉爽的卧室，怎么分别把生物钟拨准、把入睡门槛调低？
- 咖啡因和酒精是怎么偷走睡眠的？几点之后不能喝咖啡？
- 运动、午睡、压力、屏幕，分别该怎么安排才不伤觉？
- 真失眠了，CBT-I 和安眠药哪个更值得做？
- 褪黑素、镁、缬草，哪些补剂真有点用、哪些是安慰剂？
- 打鼾、轮班、时差、孕期、老年人，各自该怎么做？

## 页面特性

页面结构与交互严格对齐 [HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter) 的阅读页：

- **零外部资源**：没有 CDN、没有字体外链、不请求任何数据，断网也能读，微信里能直接传

## 重新生成

改完 `book/` 里的正文，重跑一次：

```
python build.py                # 渲染全部小节，输出 index.html
python build.py 1 3 7          # 只渲染指定小节
python build.py -o out.html    # 指定输出文件
```

零第三方依赖，Python 3.8+ 直接跑。统计数字（条目数、A/B/C、性价比三档）由脚本实时统计，写在页面页脚。

生成 PDF 版（需要 `pip install reportlab`，字体用系统自带中文字体，Windows/Linux 均可）：

```
python make_pdf.py                # 输出 how-to-sleep-better.pdf
python make_pdf.py -o out.pdf     # 指定输出文件
```

PDF 的封面、目录、前言、页眉页脚和书签由 `make_pdf.py` 自动生成，正文与统计数字同样来自 `book/` 与 `build.py` 的解析逻辑，两版内容永远一致。正文每次更新后，GitHub Actions 会同时重新生成 HTML 和 PDF 并自动提交。

改过页面交互脚本（`build.py` 里内嵌的 CSS/JS）后，跑一遍回归测试：

```
node tools/test_page.js        # 13 条断言：初始计数/章节单选/多选/开关/清空/URL
```

## 怎么贡献

正文按节拆成 16 个文件放在 `book/`，一条建议长这样：

```
### 1. 固定起床时间，比固定上床时间更重要
<!-- 成本标签: 钱=0 时间=0 毅力=否 收益=大 口径=入睡 -->
- 成本：零。
- 说人话：每天同一时间起床，生物钟就有了"锚点"，到了晚上困意会准时涨上来；比死磕几点上床更管用。
- 收益：入睡更快、白天更清醒、周末不崩，是不花一分钱的"安眠药"。
- 证据等级：A
- 来源：NSF 睡眠时长共识 (Hirshkowitz 等, 2015)；关于固定节律改善睡眠的多项 RCT
- 备注：上床时间可以浮动，起床时间尽量钉死。
```

字段顺序固定：成本 → 说人话 → 收益 → 证据等级 → 来源 → 备注。成本标签里：钱=0/少/多，时间=少/中/多，毅力=否/些/是，收益=大/中/小，口径=任意短词。性价比档由脚本按「收益量级 + 三项成本」自动算出。

**写新条目的三条规矩：**

1. 来源只引原始文献（期刊论文附 DOI 或官方链接）或官方文件；拿不准的数字标「待核实」，别硬编。
2. 「说人话」只用「收益」栏里已有的数字，不添新数，写成"哪些人、低几成"这样的日常说法。
3. 有争议的写在「备注」里，把反方证据列出来——本书不追求政治正确，追求可核对。

## 证据分级

| 等级 | 含义 |
| --- | --- |
| A | 有具体数字可查，出处是荟萃分析、大型队列或随机分组试验（RCT），或权威临床指南 |
| B | 有研究支持但说不出确切数字，或只有小样本、单项研究 |
| C | 作者经验、通行做法或官方科普，没有直接研究文献 |

**A 级只说明「有具体数字、出处可核」**，不说明一定是因果：观察性研究分不清是这件事起了作用还是做这件事的人本来就更健康；写着「随机分成两组」的才能说因果。

## 性价比口径

证据等级回答「数字可不可信」，性价比回答「值不值得做」。每条按三项成本（钱、时间、毅力）加收益量级（大/中/小）自动归档：

- 好处大、三项成本全零 = **极高**
- 好处大、成本不高，或好处中等、成本为零 = **高**
- 其余 = **一般**

**这一档是作者自己的判断，不是证据**，按本书标准它本身只算 C 级。一条可以证据 A 级、性价比一般（专业 CBT-I 治疗），也可以证据 C 级、性价比极高（把卧室窗帘换成遮光帘）。「一般」不等于不该做。
